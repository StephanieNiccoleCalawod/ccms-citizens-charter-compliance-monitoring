## S8-54 Operations API

Direct: `GET /api/reports/people`. Through the existing gateway: `GET /api/operations/reports/people`.

Parameters:

| Parameter | Values / default |
| --- | --- |
| `scope` | `office`, `person`, `all_staff`; default office for supervisors and person for Office Staff |
| `office_id` | Required for Super Admin; defaults to caller's office for office-bound roles |
| `person_id` | Person scope only; defaults to caller ID; never used to broaden staff access |
| `from`, `to` | Real ISO dates, inclusive Manila dates; default today (Asia/Manila), `to` defaults to `from` |

Example:

```text
/api/operations/reports/people?scope=all_staff&office_id=<UUID>&from=2026-11-01&to=2026-11-30
```

Response includes `scope`, `office_id`, `person_id`, `from`, `to`, `generated_at`, `totals`, `items`, `excluded_seed_count`, `note`, `basis` and `attribution`. The response uses private/no-store caching.

Each person/totals metric contains handled, completed, measured completed, on-time count and percent, completed-late count, auto-closed count, cancelled count, open count, median working minutes, recorded paused minutes, rating count/average, and `linked_complaints`.

### Measurement contract for BE Dev 2

- Cohort: transactions received by Manila **start date** in the selected period. Attribution is to `started_by`, matching the existing analytics actor attribution. This is a new source-data cohort, not the existing Oversight KPI's mixed start-date receipts/end-date results basis. BE Dev 2 must choose/use a consistent basis when wiring final reports.
- On-time percentage: on-time completed transactions divided by completed transactions with a computed compliance result. Unknown results are not silently counted as on time or late. Zero denominator returns null. `late` here counts completed requests with `is_compliant=false`; automatically closed records are returned separately as `auto_closed`.
- Typical processing time: median of recorded completed elapsed working minutes. Office median/rates are calculated over the full eligible population, not by adding/averaging staff medians or percentages.
- Paused time: sum of persisted `held_minutes`, which counts completed hold intervals. It does not invent the running duration of an active hold or claim a historical end-of-period snapshot.
- Ratings are **service ratings linked to handled transactions**, not ratings of the staff member. Unrated transactions do not enter the rating denominator.
- `linked_complaints` is **null**, with an explicit attribution explanation that complaint linkage belongs to Oversight / BE Dev 2. It is not presented as a false zero.
- Data is live as of the request, not a published/frozen historical snapshot. BE Dev 2 owns the stored report snapshot.

### D-AC-6 access and current names

- Only Super Admin, Office Head and Office Staff may use this source endpoint. Executive receives 403 and no person data.
- Office Head cannot select another office, and a person request must refer to the Head or a current active Head/Staff account returned by Identity for their office.
- Office Staff may only request `person` scope and their own account ID within their own office. SQL itself applies that person predicate; no colleague totals or roster are returned. Existing `STAFF_VIEW_REPORTS` remains an additional staff gate.
- Supervisors obtain current active roster names from Identity's existing service-key-only `/api/internal/office-accounts?office_id=...`. Unavailable/malformed membership replies fail closed with 503 `REPORT_MEMBERSHIP_UNAVAILABLE`. Identity secrets stay server-side. No stored starter-name snapshot is substituted for a current name.
- Staff self-report uses the authenticated caller name, or null. Current identities not in the roster (e.g. inactive/former handlers) are not resolved from old snapshots.
- For an Office Head's all-staff results, former/other handlers are grouped under a null `person_id` and “Other or former handlers”, preserving totals without disclosing their identities. Current staff with zero activity are included as zero rows. Super Admin may receive historical handler IDs, with null names when Identity cannot currently label them.

### K17 and reconciliation

Seed detection combines persistent `seeded_transactions` provenance and the existing reserved tracking-number suffix rule (exactly four final digits 9001–9999; 9000 is not reserved). This is server-derived and cannot be disabled by a query parameter. Seeded rows remain in the database and existing report workflow; they are excluded from every scope of this source API, including its office total, to make staff reconciliation meaningful.

All-staff totals and office-scope totals come from the same eligible cohort. Counts, recorded paused totals and rating counts reconcile, including the former/other bucket; median, percentage and average values are recomputed over the population rather than summed. Office Staff's totals are self-only.

Every response contains: **“Seeded rows are excluded from these figures (K17).”** It also returns an excluded count, restricted to the caller's authorized cohort.

## S8-55 server CSV

Existing route: `/api/reports/{id}/export.csv` in Oversight, or `/api/reports/{id}/export.csv` through the gateway's existing reports alias (the frontend's `/api/logs/reports/{id}/export.csv` also remains valid).

Filename format: `CCCMS_Report_<Office>_<MMDDYYYY>.csv`. Date is the report's generation date in Manila. Office name is sanitized for a safe ASCII attachment filename (accent normalization, separators/control characters removed), with `Office` fallback. Example: `CCCMS_Report_Office_of_Student_Affairs_11242026.csv`.

CSV retains one header row, plain headings, service names rather than codes, MM/DD/YYYY dates, CRLF rows and real UTF-8 BOM bytes `EF BB BF`. Missing service names remain visibly unavailable, not replaced with internal codes. Existing total rows, report permissions and staff report switch remain in force. String formula injection protection includes formulas hidden after leading whitespace; numeric values remain numeric.

No print/PDF layout, header/logo, signature line or page-size change was made.
